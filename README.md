# 🚀 Financial Fraud Detection System

A full-stack AI-powered financial fraud detection platform that detects, analyzes, and prevents fraudulent transactions in real time using machine learning and behavioral analytics.

---

## 📌 Features

- 🔍 Real-time fraud detection using ML models
- 📊 Interactive dashboard with analytics
- ⚠️ Fraud alerts and transaction monitoring
- 🧠 Explainable AI (why a transaction is flagged)
- 👤 Role-based access (Admin, Analyst, User)
- 💬 Integrated chatbot support
- 📈 Risk heatmaps and reports

---

### Frontend

### Backend
